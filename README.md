# Inversiones Magdezis - Login y Registro

Java (Ant) + JavaFX (Scene Builder) + BCrypt + JDBC, arquitectura en capas.

1. Ejecutar `inversiones_magdezis_in4bv.sql` en MySQL.
2. Editar `src/main/resources/db.properties`.
3. Copiar `jbcrypt.jar` y `mysql-connector-j.jar` en `lib/`.
4. Abrir la carpeta en NetBeans (File > Open Project).
5. Si su JavaFX SDK no esta en `C:/javafx-sdk`, cambiar `javafx.lib` en `nbproject/project.properties`.
6. Run Project (F6).
